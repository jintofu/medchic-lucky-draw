# Medchic_Lucky Draw

แพลตฟอร์มสำหรับการสุ่มแจกรางวัล แบ่งเป็นระบบลงทะเบียนสำหรับผู้ใช้งาน และแดชบอร์ดจัดการสำหรับแอดมิน

## วิธีการใช้งานร่วมกับ GitHub Pages
1. สร้าง Repository ใหม่ใน GitHub (เช่น `medchic-lucky-draw`)
2. อัปโหลดไฟล์ `index.html` และ `script.js` ขึ้นไป
3. ไปที่แท็บ **Settings** > **Pages**
4. ตรงส่วน Build and deployment หัวข้อ Source เลือก `Deploy from a branch` และเลือก branch `main` (หรือ `master`)
5. กด Save แล้วรอประมาณ 1-2 นาที คุณจะได้ลิงก์หน้าเว็บสำหรับเปิดใช้งานจริง


**หมายเหตุสำคัญเรื่องฐานข้อมูล:** โปรเจกต์นี้ใช้ `localStorage` หากรันบน GitHub Pages แบบคงที่ ข้อมูลของคนที่สแกนผ่านมือถือจะไม่ได้วิ่งเข้ามารวมที่หน้าจอ Admin โดยตรง เหมาะกับการใช้งานบนเครื่องเดียว หรือนำข้อมูล (Copy) ไปประมวลผลต่อ หากต้องการให้ซิงค์ข้อมูลเรียลไทม์ข้ามอุปกรณ์ แนะนำให้อัปเกรดไปผูกกับ Firebase Firestore หรือ Google Sheets API ครับ
